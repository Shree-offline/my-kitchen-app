# 🍏 Zero-Waste Kitchen Manager

A smart, full-stack inventory management system designed to reduce household food waste. Track your groceries, receive automated expiry alerts via email, and discover creative recipes based on your current fridge contents.

## ✨ Features
* **Inventory Tracking:** Simple dashboard to add, view, and delete ingredients.
* **Expiry Logic:** Visual "Critical" alerts for items expiring within 48 hours.
* **Surprise Me:** Integration with the **Spoonacular API** to suggest recipes using your available ingredients.
* **Automated Notifications:** SMTP integration to send email alerts when food is about to go bad.
* **Responsive UI:** Built with **Tailwind CSS** for a clean look on both desktop and mobile.

## 🛠️ Tech Stack
- **Backend:** Python (Flask)
- **Database:** SQLite3
- **Frontend:** HTML5, Tailwind CSS, Jinja2
- **API:** Spoonacular API
- **Deployment:** Render (Production-ready)
